WELLNESS DAILY - FULL STATIC WEBSITE

FILES
- index.html       Home page with search and category filters
- article.html     Reusable article detail page (each Read More opens this page with a unique article ID)
- about.html       About page
- contact.html     Contact form page
- style.css        Responsive website styling
- articles.js      Six sample health articles and their content
- main.js          Home page filtering and shared navigation
- article-page.js  Loads the selected article on its own page
- contact.js       Contact form mailto behaviour

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server, or open index.html in a browser.
4. Test search, category filter, each Read More link, About and Contact.

IMPORTANT BEFORE PUBLISHING
- The contact form is a frontend demo. It opens the visitor's default email application; it does not save messages online. In contact.js, replace hello@example.com with your real email address.
- The six health articles are starter educational content. Review them, add reliable references, author/editor information and a content review date before publishing. They are not medical advice.
- This is a static HTML/CSS/JavaScript website. It does not include a backend, database, login or admin dashboard.
